# newo-openai-plugin

Newo Agent Builder plugin for Codex and ChatGPT.

## Install in Codex from GitHub

```bash
codex plugin marketplace add newo-ai/newo-openai-plugin
codex plugin add newo-agent-builder@newo
```

Sign-in to the Newo MCP server goes through Auth0 and returns to `http://localhost:8765/callback`, so port 8765 must
be free while signing in.
